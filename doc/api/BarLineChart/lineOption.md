格式：

```d
lineOption: {
  dataName: ['Domestic'],
  lineColor: ['red']
  ...
};
```

说明：折线图配置项，dataName为折线图显示的数据，lineColor为折线图颜色，其余详细参数见折线图LineChart配置
<p class='ev_expand_title'>lineOption.dataName<span class='ev_expand_required'>必填</span><span class='ev_expand_defaults'>无默认值</span><span class='ev_expand_type'>Array</span>


<p class='ev_expand_introduce'>说明：折线图显示的数据

<p class='ev_expand_title'>lineOption.lineColor<span class='ev_expand_required'>非必填</span><span class='ev_expand_defaults'>有默认值</span><span class='ev_expand_type'>Array</span>
<p class='ev_expand_introduce'>默认值为成功色

<p class='ev_expand_introduce'>说明：折线图显示的数据

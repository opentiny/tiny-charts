说明：对齐 echarts 的 `title` 属性，替代旧属性`text`，默认中心文本自动居中对齐

格式：

```d
title:{
    text: " ",
    subtext: " ",
    top: 'middle',
    left: 'center',
    textAlign: 'center',
    itemGap: 16,
    textStyle: {
        color: '#191919',
        fontSize: 60,
        fontWeight: 'normal'
    },
    subtextStyle: {
        color: '#bbbbbb',
        fontSize: 20,
    },
}
```
